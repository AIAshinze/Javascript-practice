# Health Census App

A healthcare data analysis interface built with HTML and vanilla JavaScript.

## About

This project demonstrates how to build an interactive patient data collection and reporting system. It covers DOM manipulation, form handling, data filtering, and dynamic report generation — all applied in a healthcare analytics context.

## Learning Objectives

- **Interactive Data Input** — Build HTML forms with validation, handling text, radio buttons, number inputs, and dropdowns
- **Data Processing & Analysis** — Store and filter patient records using JavaScript arrays of objects
- **Dynamic Report Generation** — Update the DOM in real time to display statistical insights from collected data
- **Event Handling** — Respond to button clicks and navigation events with appropriate search/filter logic

## Prerequisites

- Basic HTML and GitHub knowledge
- Familiarity with arrays, array methods, strings, objects, and functions
- A web browser with DevTools (Chrome, Firefox, etc.)

## Tech Stack

`HTML` `CSS` `JavaScript (Vanilla)`

## Key Concepts Practiced

- DOM manipulation
- Form data collection and validation
- Array filtering and data aggregation
- Data-driven UI updates
